# Portfolio cá nhân — Nguyễn Ngọc Lam Trường

## Các tệp
- `index.html`: nội dung và cấu trúc Semantic HTML5
- `style.css`: giao diện, CSS Variables, Flexbox/Grid, responsive, hover/focus
- `script.js`: menu di động, AOS, năm hiện tại và nút quay lại đầu trang
- `PROMPT_LOG.md`: nhật ký Prompt Engineering
- `assets/`: thư mục chứa hình ảnh/tài nguyên bổ sung

## Chạy website
Mở `index.html` bằng trình duyệt. Các thư viện Animate.css, AOS và Google Fonts được tải qua CDN nên cần kết nối Internet để hiển thị đầy đủ.

## Đưa lên GitHub Pages
1. Tạo repository **Public** với tên theo đúng cú pháp giảng viên yêu cầu: `Ten_Ho_MSSV`.
2. Upload các tệp ở thư mục gốc repository.
3. Mở **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, folder `/(root)`, bấm **Save**.
5. Chờ GitHub Pages xuất bản, mở link để kiểm tra và thêm link vào mô tả repository.

## Kiểm tra trước khi nộp
- Xác nhận MSSV trong `PROMPT_LOG.md`.
- Thay `your-email@example.com` bằng email thật trong `index.html`.
- Kiểm tra nội dung kỹ năng và dự án có đúng thực tế; các dự án hiện tại là mẫu trình bày.
- Kiểm tra website trên máy tính và điện thoại.
